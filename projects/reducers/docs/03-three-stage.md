## 2. 最终设计参数

### 2.1 齿轮

m = 3，α = 20°，hₐ\* = 1.0，c\* = 0.25，齿宽 b = 40。

| 齿轮 | z | 分度圆 | 齿顶圆 | 齿根圆 | 所在轴 | 轴向区段 (Z) |
|---|---|---|---|---|---|---|
| z1 | 20 | Ø60 | Ø66 | Ø52.5 | I | 0 – 40 |
| z2 | 80 | Ø240 | Ø246 | Ø232.5 | II | 0 – 40 |
| z3 | 38 | Ø114 | Ø120 | Ø106.5 | II | 45 – 85 |
| z4 | 76 | Ø228 | Ø234 | Ø220.5 | III | 45 – 85 |
| z5 | 56 | Ø168 | Ø174 | Ø160.5 | III | 90 – 130 |
| z6 | 56 | Ø168 | Ø174 | Ø160.5 | IV | 90 – 130 |

齿数比：80/20 = **4.000**，76/38 = **2.000**，56/56 = **1.000**，总 **8.000**。

轴心（Y）：I = 0，II = 150，III = 321，IV = 489。
中心距：a₁₂ = 150，a₂₃ = 171，a₃₄ = 168。

**齿数是被重配过的**（第一轮是 20/80/20/40/30/30）。原因：展开式布局要求第一级
大齿轮的齿顶圆让开下一根轴，即

```
da₂/2 + d_III(轴颈)/2 + Δ  <  a₂
```

第一轮 20/80/20/40 时 da₂/2 = 123 而 a₂ = 90，齿顶**扫过 III 轴中心线 33 mm**，
三级齿轮被迫沿轴向错开 180 mm，III 轴就无法伸到第一级的轴向区段去装轴承——
箱体做不成标准两壁结构。

重配后：`123 + 22.5 = 145.5 < 171`（余量 25.5），
`117 + 27.5 = 144.5 < 168`（余量 23.5），三级齿轮得以收进同一轴向区段
（三个 40 mm 齿宽带，带间 5 mm）。

### 2.2 轮齿相位

`PartDesign.fcgear` 把齿中心放在局部 0°，齿槽中心在 `180/z`。对每一对啮合
（小轮在低 Y 侧）：

```
φ_小轮 = 90°                        （齿中心指向 +Y）
φ_大轮 = 270° − 180°/z_大轮          （齿槽中心指回 −Y）
```

实际取值：z1 90°，z2 267.750°，z3 90°，z4 267.6316°，z5 90°，z6 266.7857°。

### 2.3 轴系

四根轴都是阶梯轴，带轴承轴颈、定位轴肩、装拆台阶（轴承从轴端滑入并靠轴肩
定位）。z1 / z3 / z5 为**整体齿轮轴**。

|---|---|---|---|---|
| I（输入） | 6207 | Ø35 | 齿体 Ø52.4 | Ø30，Z −100…−40 |
| II | 6208 | Ø40 | z2 座 Ø45 / 齿体 Ø106.4 | 无 |
| III | 6209 | Ø45 | z4 座 Ø50 / 齿体 Ø160.4 | 无 |
| IV（输出） | 6211 | Ø55 | z6 座 Ø60 | Ø48，Z 174…250 |

平键按 GB/T 1096，键长 36：

| 齿轮 | 轴径 | 键 | t₁ | t₂ |
|---|---|---|---|---|
| z2 | Ø45 | 14×9 | 5.5 | 3.8 |
| z4 | Ø50 | 16×10 | 6.0 | 4.3 |
| z6 | Ø60 | 18×11 | 7.0 | 4.4 |

### 2.5 轴承与端盖

8 套深沟球轴承，每套含内圈、外圈、9 颗滚球，做成 `Part.makeCompound` 复合体。
8 个端盖：**2 个透盖**（输入轴 Ø30 油封 30×47×7、输出轴 Ø48 油封 48×72×8）
+ **6 个闷盖**；每个端盖 6×M8，止口 6 mm。
端盖螺栓在凸台里配 Ø6.8×16 螺纹底孔。

### 2.6 标准附件

## 3. 过程

### 3.1 第一轮：仅传动系统

先探测远程 API：`Gui` 模块不可用、`App.Vector` 不存在，但
`PartDesign.fcgear` 可通过 `fcgear.fcgear.FCWireBuilder` 调用。

动手前先用**布尔干涉量**验证啮合相位公式：正确相位下 `common()` 体积 = 0，
把从动轮再转过半个齿距则得到 ~1900 mm³ 干涉——先确认这个判据有区分度，再拿它
当尺子用（见 [verification methodology §5](../../../docs/practices/03-verification-methodology.md#5-prove-the-check-has-discriminating-power)）。

然后建 6 齿轮 + 4 轴 + 3 键，45 对零件干涉全为 0。

### 3.2 第二轮：完整减速器

**先发现齿数不可用**（见 2.1），重配齿数 → 重建传动系 → 建箱座/箱盖 →
建轴承/端盖 → 补附件。

这一轮踩的坑最多，按被发现顺序：

| # | 现象 | 根因 | 对策 |
|---|---|---|---|
| 1 | 箱体与传动系**全部**干涉 | 剖分凸缘是实体板，我**先切内腔后并凸缘**，凸缘把内腔填实了 | 改为先并完所有凸缘/凸台，**最后**切内腔 |
| 2 | 轴伸与箱体干涉 | 剖分凸缘沿 ±Z 外伸 35 挡住了轴伸 | 在每个轴承座处挖避让孔（半径 = 凸台半径 + 8，Z 只到凸台端面） |
| 3 | 凸缘螺栓与箱座干涉 26905 mm³ | 凸缘在 Z 向不外伸，螺母埋在箱座实体里 | 给 Z 向外伸（配合 #2 的避让孔） |
| 4 | 轴承内圈与轴干涉 | 内圈内孔半径写成了 `d/2 − 1`（比轴颈小 1 mm） | 改为 `d/2 + 0.05`（0.1 mm 间隙） |
| 5 | 闷盖与端盖螺栓干涉 3619 mm³ | `end_cap()` 里的螺栓孔布尔**静默未生效** | 单独再切一次螺栓孔；螺栓分 Ø8 穿盖段 + Ø6.6 入螺孔段 |
| 6 | 凸缘螺栓头与端壁加强肋干涉 | 六角头外接圆 0.577·af 与肋相碰 | 肋从 Z=30/110 挪到 Z=45/95 |
| 7 | 起盖螺钉与凸缘螺栓干涉 | 两者间距 14.8 < 所需 19.6 | 挪到 Y 向凸缘中部（Z=45 / 145） |
| 8 | 螺栓头/螺母端面与凸缘面残留 111 mm³ 干涉 | 精确共面产生数值薄片 | 端面内缩 0.2 mm |

期间还出现过一次**误判为卡死**：最后那条全量校验（41 件 820 对）跑了 2 分钟
多，用户以为 FreeCAD 挂了。`get_rpc_status` 报 `state: busy` 才确认是在跑。
之后改成包围盒预筛，820 → 201 对，秒级完成（见 [§2](../../../docs/practices/03-verification-methodology.md#2-pre-filter-large-pairwise-sweeps-with-bounding-boxes) 与 [§9](../../../docs/practices/03-verification-methodology.md#9-distinguish-still-running-from-hung)）。

### 3.3 第三轮：透明

箱座/箱盖 `ViewObject.Transparency = 75`，便于看内部传动系。

### 3.4 第四轮：清理多余结构

用户指出通气器「游离在主体外」。用**连通性分析**（包围盒重叠 + 并查集）定量
确认：`Breather` 自成连通分量，**离最近零件 50.3 mm**。

根因是**建模辅助函数的轴向 bug**：我用沿 +Z 构建的 `cyl()` 去造通气器（它应沿
+X），而 `.translated()` 只平移、不换轴。同一轮还查出放油螺塞的六角头也拐错了
方向——`hex_prism(..., axis='Y')` 只实现了 `'X'` 分支，非法取值被**静默忽略**。

两处都改为显式指定轴线后重建，并顺手把螺塞头部与凸台端面的 3 mm 缝隙贴平
（基准面取错：把箱壁外表面 Y=603 当成了凸台端面 Y=619）。

## 5. 与仓库约定的偏差

### 5.1 坐标系（重要）

| | 本仓库约定 | 本次模型 |
|---|---|---|
| 轴方向 | **+X** | **+Z** |
| 轴心所在平面 | z = 0 | y = 0 |
| 剖分面 | z = 0 | **X = 0** |
| 齿轮局部系 | 轴 +Z、齿中心局部 +X | 同（一致） |
| 箱座/箱盖 | `Housing_Base` (z<0) / `Housing_Cover` (z>0) | `HousingBase` (X<0) / `HousingCover` (X>0) |

两套系的 `Placement`、相位公式、端盖/轴承的轴向定义、视图方向全都不同。三级模型
若要并入本仓库，需要整体旋转到 +X / z=0 系，**不能**直接混用。

### 5.2 未复用仓库的工具

本次没有 import `src/common.py`，而是在远程手搓脚本（常量写成一个
`reducer_params.py` 模块 import 以避免漂移）。代价是重复实现且偏离约定；
仓库里已有的 `mesh_phases()`、`key_for()`、`make_bearing()`、`make_end_cap()`、
`cap_dimensions()` 本都可以直接用。

### 5.3 命名

仓库用 `Housing_Base` / `Housing_Cover` / `Gear_*` / `Shaft_*`（带下划线前缀），
本次用了 `HousingBase` / `HousingCover`。

## 8. 经验教训

完整的坑清单在 [`docs/practices/`](../../../docs/practices/)，其中带 `[3rd]`
标记的条目来自本次会话。最值得记住的三条：

1. **先并后挖**：箱体类零件的凸缘是实体板，必须并完所有凸台再切内腔。
2. **大批量干涉校验先做包围盒预筛**：820 对要 2 分钟且看起来像死机，
   预筛后秒级完成、结论不变。
3. **辅助函数要把「轴」写进名字或做参数校验**：沿 Z 的 `cyl()` 被
   `.translated()` 调用时不会报错，只会静默产出错轴零件。
